# Twitter Clone using Tailwind CSS

A responsive Twitter/X clone built using HTML and Tailwind CSS.

## About the Project

This project is a frontend clone of Twitter (X), created for learning and practicing frontend web development and Tailwind CSS.

It includes a Twitter-like interface with:

- Home feed
- For You / Following sections
- Tweet composer
- User profiles
- Tweet cards
- Like, comment, repost and view icons
- Sidebar navigation
- Responsive layout
- Dark theme

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Node.js / npm
